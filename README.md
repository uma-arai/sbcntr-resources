# sbcntr-resources

書籍「AWSコンテナ設計・構築[本格]入門 増補改訂版」の用の各種リソースのダウンロードリポジトリです。
初版をご購入した方は、`main`ブランチをご参照ください。

## リポジトリの構成

```bash
 ❯ tree -d -L 2 .
├── handson
│   ├── chap6-2
│   ├── chap6-6
│   ├── cloudformations
│   ├── fis
│   ├── stepfunctions
│   ├── waf
│   └── xray
└── iam
```

本書でPDFからコードをコピー＆ペーストしたり、写経するのが難しい場合がありますので、是非ご活用ください。
